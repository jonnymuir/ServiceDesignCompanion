# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub's private vulnerability reporting](https://github.com/jonnymuir/ServiceDesignCompanion/security/advisories/new),
not in a public issue or pull request. Include the version, what an attacker can do, and the steps
to reproduce it.

This is a solo-maintained project, so reports are answered as soon as possible rather than against
a fixed timescale. Fixes are credited in the advisory unless you'd rather not be named.

## Supported versions

Only the latest release receives security fixes.

## Scope

In scope: the Service Design Companion website and its iOS and Android apps. Of particular
interest: anything that exposes data the app says it does not collect, or lets a visitor change
published content.

The app holds no user accounts or personal data on the server, so reports about account takeover
do not apply.
